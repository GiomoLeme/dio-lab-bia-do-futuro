# Pitch — FinEdu

## Sobre o pitch

O pitch apresenta o FinEdu, assistente virtual de educação financeira desenvolvido como projeto final do Bootcamp Bradesco + DIO.

A apresentação aborda:

- o problema de tornar conceitos financeiros mais acessíveis;
- a proposta do FinEdu;
- o uso de Python, Streamlit, Ollama e Gemma 3;
- a utilização de dados fictícios como base de conhecimento;
- regras de segurança e limitações do agente;
- uma demonstração prática da aplicação.

## Estrutura

- Problema
- Solução
- Demonstração
- Diferenciais e aprendizados
